# 📺 IPTV Player - برنامه پخش‌کننده IPTV

یک برنامه پخش‌کننده IPTV مدرن و قابل استفاده ساخته شده با Flask و JavaScript. تماشای شبکه‌های تلویزیونی زنده از منابع مختلف با رابط کاربری زیبا و واکنش‌گرا.

## ✨ ویژگی‌ها

- 📹 **پخش تلویزیون زنده** - تماشای شبکه‌ها از پلی‌لیست M3U8
- 🔍 **جستجو و فیلتر** - جستجوی شبکه‌ها بر اساس نام یا دسته‌بندی
- 📂 **دسته‌بندی شبکه‌ها** - مرور شبکه‌ها بر اساس گروه‌ها
- ⭐ **علاقه‌مندی‌ها** - ذخیره شبکه‌های مورد علاقه (localStorage)
- 🌙 **حالت تاریک/روشن** - تبدیل بین تم‌های تاریک و روشن
- 📱 **طراحی واکنش‌گرا** - کار بر روی دسکتاپ، تبلت و موبایل
- 🎨 **رابط کاربری زیبا** - رابط مدرن و قابل استفاده
- 📊 **آمار شبکه‌ها** - مشاهده آمار شبکه‌ها
- 🔄 **بارگیری مجدد خودکار** - بارگیری دوباره پلی‌لیست از فایل

## 🚀 شروع سریع

### پیش‌نیازها
- Python 3.7+
- pip (مدیر بسته Python)

### نصب و راه‌اندازی

1. **دریافت یا کلون پروژه**
```bash
cd IPTV
```

2. **نصب وابستگی‌ها**
```bash
pip install -r requirements.txt
```

3. **اجرای برنامه**
```bash
python app.py
```

4. **باز کردن در مرورگر**
```
http://localhost:5000
```

## ⚙️ پیکربندی

### فایل پلی‌لیست
برنامه شبکه‌ها را از `playlist.m3u8` می‌خواند. فرمت:
```
#EXTINF:-1 tvg-logo="URL" group-title="دسته‌بندی",نام شبکه
http://stream-url.com/live.m3u8
```

### تغییر پورت
برای تغییر پورت، `app.py` را ویرایش کنید:
```python
app.run(debug=True, host='0.0.0.0', port=5000)
```

## 📡 نقاط پایانی API

| نقطه پایانی | روش | توضیح |
|----------|------|--------|
| `/` | GET | صفحه اصلی پخش‌کننده |
| `/api/channels` | GET | دریافت تمام شبکه‌ها (با فیلتر اختیاری) |
| `/api/groups` | GET | دریافت تمام دسته‌بندی‌ها |
| `/api/stats` | GET | دریافت آمار پلی‌لیست |
| `/api/channel/<id>` | GET | دریافت شبکه خاص |
| `/api/reload` | POST | بارگیری مجدد پلی‌لیست |

### پارامترهای Query

**GET `/api/channels`:**
- `group` - فیلتر بر اساس دسته‌بندی (اختیاری)
- `search` - جستجو بر اساس نام شبکه (اختیاری)

مثال:
```
/api/channels?group=ورزشی&search=فوتبال
```

## 🎯 نحوه استفاده

1. **مرور شبکه‌ها** - انتخاب یک دسته‌بندی از نوار کناری
2. **جستجو** - استفاده از جعبه جستجو برای یافتن شبکه‌ها
3. **پخش** - کلیک بر روی کارت شبکه برای شروع پخش
4. **علاقه‌مندی** - کلیک بر روی ستاره برای اضافه/حذف از علاقه‌مندی‌ها
5. **تم** - کلیک بر روی ماه برای تبدیل حالت تاریک/روشن
6. **تازه‌سازی** - کلیک بر روی دکمه تازه‌سازی برای بارگیری مجدد

## 🌙 ویژگی‌های تفصیلی

### حالت تاریک
- خودکار با تم سیستم یا دستی
- ذخیره ترجیح در localStorage
- کلیک بر روی آیکون ماه برای تبدیل

### علاقه‌مندی‌ها
- کلیک بر روی ستاره برای ذخیره شبکه
- ذخیره شده در browser localStorage
- دوام در میان جلسات

### جستجو
- فیلتر کردن بلادرنگ هنگام تایپ
- جستجو در نام شبکه‌ها
- کار با فیلتر دسته‌بندی فعلی

## 🐛 حل مشکلات

**شبکه‌ها بارگذاری نمی‌شوند؟**
- اطمینان حاصل کنید که `playlist.m3u8` در دایرکتوری اصلی وجود دارد
- بررسی کنسول برای خطاها (F12 → Console)
- تصدیق فرمت M3U8

**ویدیو پخش نمی‌شود؟**
- ممکن است برخی از جریان‌ها دارای محدودیت جغرافیایی باشند
- بررسی URL جریان در کنسول مرورگر
- سعی کنید شبکه‌های مختلفی استفاده کنید

**پورت قبلاً در استفاده است؟**
- پورت را در `app.py` تغییر دهید
- یا فرآیند را بسته کنید: `lsof -ti:5000 | xargs kill -9`

## 🚀 استقرار

### Heroku
1. ایجاد `Procfile`:
```
web: gunicorn app:app
```

2. استقرار:
```bash
git push heroku main
```

### Docker
ایجاد `Dockerfile`:
```dockerfile
FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["gunicorn", "app:app"]
```
